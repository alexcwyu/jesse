Design decisions

Decision Rationale Tradeoff Evidence
Validate route uniqueness and common quote asset. One strategy per exchange-symbol avoids position conflicts; common quote enables comparable aggregate metrics. Multi-route research cannot mix quote currencies without conversion changes. RouterClass.initiate (L19)
Switch replay by source availability shape. Sparse/gapped instrument histories preserve observed timestamps while dense aligned data uses legacy fast paths. Multiple simulation paths need independent coverage; fast mode is not blanket vectorization. simulator (L541) / _timestamp_simulator (L910)

Workflow

Route-based historical strategy run

This is native historical execution. Actual live/paper sessions require jesse-live; local Sandbox is not a live paper-trading exchange adapter.

Diagram source

  W0 --> W1
  W2["Bind position/Broker and run strategy at timeframe boundaries."]
  W1 --> W2
  W3["Broker routes price/qty to API and local Sandbox order service."]
  W2 --> W3
  W4["Track long/short PnL and configured margin model."]
  W3 --> W4

  2. Choose dense step/skip or observed timestamp replay.. simulator (L541)

  4. Broker routes price/qty to API and local Sandbox order service.. Broker.buy_at (L67) / API.initiate_driver (L30) / Sandbox.limit_order (L27)
  5. Track long/short PnL and configured margin model.. Position.pnl (L152) / Position.liquidation_price (L216)

Strengths and limits

Strengths

  • Observed-timestamp replay explicitly preserves gaps/unequal source timelines instead of assuming every instrument has a dense minute index. simulator (L541) / _timestamp_simulator (L910)

Limitations

  • Live and real-time paper trading depend on jesse-live, while native Sandbox serves offline simulation. live (L33) / API.initiate_driver (L30) / Sandbox.limit_order (L27)
  • Router rejects mixed quote assets and duplicate exchange-symbol routes. RouterClass.initiate (L19)
